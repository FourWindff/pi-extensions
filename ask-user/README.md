# pi 提问表单扩展（ask_user）

给模型一个「一次问完 + 逐个作答 + 复核后发送」的提问表单。它只做工具，不管模式：**三个模式都能用**，只有画不出终端界面的会话（`--mode json` / print / rpc，以及子 agent 子进程）会在启动时把它从活动工具集里摘掉。

## 交互

模型把要确认的问题攒进一次 `ask_user` 调用：

```jsonc
{ "questions": [
  { "question": "Which database?", "options": ["postgres", "mysql"] }, // 可以选，也可以自己写
  { "question": "Anything else?" }                                     // 没 options 就是纯输入
] }
```

1. **所有问题放在同一张可滚动表单中**，用户从第一条开始答。当前问题下面要么是选项列表（`↑↓` 选，最后一行 `✎ Type an answer…` 打开编辑器），要么直接就是编辑器（可多行，`Shift+Enter` 或 `Ctrl+J` 换行）。
2. **一次答一个**：Enter 确认并自动下移，表单跟随当前问题和选中项。窗口较小时，可以向上滚动查看已填答案。
3. **答完进复核步骤**：所有问答对列一遍，只有在这里按 Enter 才是正式发送（答案作为工具结果回到模型）。空着确认的题目标成 `(no answer)`；在选项题里手写的答案标成 `(wrote) …`，选出来的不标（选项题里这个区别对模型有信息量，纯输入题没有）。

按键：`Enter` 确认/发送、`↑↓` 在选项里移动、`PageUp` / `PageDown` 滚动整张表单（使用 Pi 的选择列表翻页快捷键）。全屏模式下也可以在表单上使用鼠标滚轮；普通模式使用键盘翻页。滚动查看后，继续输入或移动选项会重新跟随当前位置。`Esc` 往回退一层——编辑器里有选项的题目退回选项列表，选项列表（或纯输入题）退回上一条，第一条问题处 `Esc` 取消整个表单（模型收到「用户取消了」）。退到某条时，选过的选项高亮回原位，手写过的那条重新打开编辑器并带上原文。

## 在哪些模式可用

扩展本身不区分模式，谁能不能用由两点决定：

- **build**：pi 把新注册的工具直接放进活动集，所以 build 默认就有；想关就 `/tools`（关掉会被记进 build 的工具集快照，切模式回来仍然是关的）。
- **plan / ask**：由模式文件的白名单决定。`mode-switching/plan.md` 与 `ask.md` 的 `tools` 里写着 `ask_user`——那行只是字符串，删掉该模式就没有它。
- **非 TUI**：`ctx.ui.custom` 画不出来，所以 `session_start` 里只要 `ctx.mode !== "tui"` 就把它从活动集摘掉。子 agent 是 `--mode json -p` 起的，同样看不到它。万一有调用已经在飞，工具只回一句「需要交互界面，请用纯文本提问」。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.ts` | 工具定义 + 表单渲染/按键 + 非 TUI 会话里摘掉自己 |
| `questionFlow.ts` | 状态机（纯函数，不 import pi / 不碰终端） |
| `questionFlow.test.ts` | 问答状态机测试 |
| `layout.test.mjs` | 使用已安装 Pi 的真实 TUI 渲染器测试布局、滚动与缩放 |

## 测试

```bash
cd ~/.pi/agent/extensions/ask-user
node --test
```

状态机测试覆盖选项挑选、手写答案（`(wrote)`）、逐层回退和空答案汇总；布局测试覆盖小窗口、选项跟随、复核翻页、鼠标滚轮、中文输入和窗口缩放。布局测试默认使用本机 Pi 托管安装，其他安装可通过 `PI_TEST_CODING_AGENT_DIR` 指向 `@earendil-works/pi-coding-agent` 包目录。

## 手工验证清单

1. build 里 `/tools` 能看到 `ask_user`；shift+tab 切到 plan / ask 后仍然有。
2. 让模型问两个问题（其中一个带选项）：一次列完 → `↑↓` 选 / 选到 `✎ Type an answer…` 手写 / 纯输入题直接打字 → 复核屏 Enter 才发送。
3. `Esc` 逐层回退、第一条问题处 `Esc` 取消，两条路径都试一遍。
4. 用 `/tools` 在 build 里关掉它 → 切到 plan 再切回来，它仍然是关的（快照记的是你的选择）。
5. `pi -p "…"`（非 TUI）里它不在工具表里。
